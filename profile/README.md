# HappyFruitFly 🪰

> **초파리 Connectome × AI — 생물학적 신경망 기반 재난 대피 연구**

실제 **초파리 뇌의 신경 연결 구조(Connectome)** 를 기반으로 신경망을 구현하고,  
기존 인공신경망(ANN)과의 **강건성 및 일반화 성능을 비교·분석**하여  
대형 건축물의 동적 재난 상황에 적용하는 캡스톤 프로젝트입니다.

## 🪰 프로젝트

- **HappyFruitFly** — 초파리 Connectome 기반 동적 재난 대피 경로 탐색 및 강건성 연구

## 🔬 연구 방향

- 실제 **초파리 Connectome 기반 신경망 구조** 구현
- 기존 **인공신경망(ANN)** 과 동일 환경 비교
- 백화점·복합쇼핑몰 등 **대형 건축물 대피 환경** 구축
- 화재·연기·통로 폐쇄 등 **동적 재난 상황** 구현
- CCTV·센서 손실 상황에서 **신경망 강건성 비교**
- 미학습 건물 및 새로운 재난 상황에서 **일반화 성능 분석**
- 대피 성공률·소요 시간·위험 노출·성능 저하 등 비교
- 연구 결과를 활용한 **웹앱 기반 지능형 재난 대피 안내 시스템** 구현

## 🧪 핵심 비교

**ANN vs Drosophila Connectome-Based Neural Network**

동일한 재난 환경에서 두 신경망을 학습·평가하여  
환경 변화와 감각 정보 손실에 따른 성능 차이를 분석합니다.
