# Indoor Navigation Network Automation 🗺️

> **SHP × POI — 실내 길찾기 네트워크 자동 구축 및 관리 웹 시스템**

기존 **SHP 공간정보와 POI 데이터**를 활용하여  
실내 길찾기에 필요한 **Node/Link Network를 자동으로 생성**하고,  
생성된 결과의 검수·수정·테스트 과정을 하나의 웹 환경에서 수행할 수 있도록 하는 캡스톤 프로젝트입니다.

## 🗺️ 프로젝트

- **실내 길찾기 네트워크 자동 구축 및 관리 웹 시스템**
- **Web-Based System for Automated Indoor Navigation Network Construction and Management**

## 🛠️ 개발 방향

- **SHP 공간정보 데이터** 업로드 및 분석
- 매장·화장실·엘리베이터·계단 등 **POI 데이터** 연동
- 건물 공간정보의 **웹 지도 시각화**
- 실내 길찾기용 **Node/Link Network 자동 생성**
- 생성된 Node/Link의 **웹 기반 검수 및 수정**
- 잘못된 경로의 추가·삭제·연결 등 **Network 편집 기능**
- 출발지·목적지 설정을 통한 **길찾기 테스트**
- 반복적인 실내 길찾기 Network 구축 작업의 **자동화 및 간소화**

## 🔄 핵심 Workflow

**SHP + POI → 공간정보 시각화 → Node/Link Network 자동 생성 → 검수·수정 → 길찾기 테스트**

기존 공간정보를 활용하여 작업자가 직접 수행하던  
**실내 길찾기 Network 구축 및 검수 과정을 웹에서 자동화·간소화**하는 것을 목표로 합니다.
