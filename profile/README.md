# QuantVeritas

> **Quant + Veritas** — 데이터로 검증하는 매매 신호.

AI로 차트 지표와 뉴스를 교차 검증해, 근거 있는 매수·매도 시점을 찾는 것을 목표로 하는
스마트ICT융합캡스톤 팀입니다.

### 🚀 프로젝트
- **[signal-scout](https://github.com/QuantVeritas/signal-scout)** — 기술적 지표 + 뉴스 + LLM 교차검증 기반 주식 트레이딩 봇

### 🧭 원칙
- 신호는 **근거와 함께** — 왜 사고 파는지 설명할 수 있어야 한다
- 실매매 전 **백테스트·모의매매로 검증**
- 커밋 컨벤션·브랜치 전략을 지켜 **개발 이력이 곧 문서**가 되게
